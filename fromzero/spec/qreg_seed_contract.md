# QReg 确定性种子映射合同 v0.1

`qreg`(算子 op=6)是星算语**确定性随机源**:同一 seed → 同一序列,跨 C / Rust / C# / 星算语自研逐位一致,替代非确定性 `rand`。这是 v0.1 语义规范 §5 确定性铁律在随机性上的落实。

## 用途

- 向量/权重确定性初始化(bge-m3 风格分布、embedding 种子)
- 量子寄存器采样的确定性坍缩(坍缩路径由 seed 决定,可复现)
- 训练扰动/退火的确定性源

## 算法:PCG32(XSH-RR)

纯整数运算、零平台依赖、跨语言可精确复现。

| 量 | 值 |
|---|---|
| 状态 `state` | uint64 |
| 增量 `INC` | `1442695040888963407` |
| 乘子 `MULT` | `6364136223846793005` |
| 掩码 `MASK` | `0xFFFFFFFFFFFFFFFF` |

**初始化**:`state = (uint64)seed + INC`

**每步输出**(一步一输出,无消耗步):
1. `state = (state * MULT + INC) & MASK`
2. `xorshifted = (state >> 18) ^ state`
3. `rot = state >> 59`
4. `out32 = ((xorshifted >> (32 - rot)) | (xorshifted << rot)) & 0xFFFFFFFF`

## 映射到 float[0,1)

`f = (out32 >> 8) * (1.0 / 2^24)` —— 用移位+精确倒数避免不同平台舍入差异。

## 版本化

- 本合同版本:**v0.1**
- 任何算法/初始化/输出的变更必须递增版本号,并重新生成 golden 样例;否则违反确定性铁律。

## Golden 样例(seed = 42)

前 6 个 `uint32` 输出:

| 序号 | uint32(hex) | float[0,1) |
|---|---|---|
| 1 | `0x7f7aa885` | 0.497965367 |
| 2 | `0xaf88544a` | 0.685673969 |
| 3 | `0xdbdfefb8` | 0.858885748 |
| 4 | `0xdc5aabb0` | 0.860758524 |
| 5 | `0xbd67d2db` | 0.739865473 |
| 6 | `0x7dd7d086` | 0.491574319 |

所有实现(qreg 的 C / Rust / C# / 星算语自研)跑 seed=42 必须逐位吐出上述序列,否则编译期门禁拦截。
