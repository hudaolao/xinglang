# 星算语 v0.2 · 训练级 IR 规范(XL01 扩展)

> **里程碑**: P2 收口 = P3 的② · 把因果线性注意力训练表达成统一字节码
> **铁则**: 训练 IR 仍走统一 XL01 发射 + Rust 门禁 + 五项哈希 golden, 不搞平行执行栈

---

## 1. 算子扩展(11 → 16)

v0.1 冻结 11 算子; 线性注意力训练需新增 5 个训练算子:

| opcode | 算子 | 语义 | 对应 P2 C 实现 |
|--------|------|------|---------------|
| 12 | `rms_norm` | RMS 归一化(仅含平方均值, 无均值减除) | `RQ/RK = sqrt(Σq²/D)+eps`, q/k 归一 |
| 13 | `elu` | 指数线性单元核, 键构造 `elu(k)+1` | `elu(x)` |
| 14 | `linear_attn_fwd` | 因果线性注意力前向(块级流): state+=k⊗v, z+=k, y=(state·q)/\|z·q\| | forward 的 state/z/Y |
| 15 | `linear_attn_bwd` | 线性注意力反向(按 t 回推维护 state/z 梯度) | backward |
| 16 | `clip_grad` | 梯度裁剪(范数上界) | 梯度裁剪 |

三符语义: `▸` 锚定参数/张量(符号层), `↦` 标记精度域(神经层), `⟶` 包裹块级流算子(量子/流式层, 禁全量驻留)。

## 2. 训练 IR 结构(每 step 的标准算子流)

```
qreg(seed)                       # 6  确定性权重初始化(种子→序列映射)
▸ params                         # 8  符号锚定参数
↦ embed                          # 9  神经层入口
Q = matmul(Wq, X)                # 1  Q 投影
K = matmul(Wk, X)                # 1  K 投影
V = matmul(Wv, X)                # 1  V 投影
Q' = rms_norm(Q)                 # 12 RMS 归一化
K' = rms_norm(K)                 # 12
⟶ y = linear_attn_fwd(Q',K',V)   # 10+14 块级流: state/z 增量 + den 输出
logits = matmul(Wo, y)           # 1 输出投影
loss = cross_entropy(logits, S)  # 5 损失
⟶ g = linear_attn_bwd(...)       # 10+15 反向(块级流)
g = clip_grad(g)                 # 16 梯度裁剪
w = adamw(lr)                    # 11 参数更新
```

**确定性**: 算子顺序固定、归约树固定、PCG32 种子→序列版本化。同一源码 → 同一训练级字节码 → 逐位一致执行。

## 3. 五项哈希 golden(训练级)

每个训练测试用例输出并锁定:
1. 字节码哈希(训练IR 发射结果)
2. 资源预算报告哈希(参数/优化器/激活/运行时四栏)
3. 执行 trace 哈希(整数事件 + 浮点值, 可重放)
4. 固定归约浮点值哈希
5. **loss 序列哈希**(训练逐步 loss, 可复现)

## 4. 验收

- 训练 IR 过 Rust 门禁(预算误差≤5%, 块级流禁全量驻留)
- 单线程/8 线程逐位一致
- 峰值内存 ≤3.5GB(1M 参数)
- 与 P2 C 实现(因果线性注意力)loss 曲线对齐
