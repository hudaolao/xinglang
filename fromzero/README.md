# ⚛ 星算语 XingLang · fromzero 基座工程

**多源头存算一体语言 + 从零随机初始化训练全新基座。**

从零手搓一门**存算一体**的新语言——统一 XL01 字节码、**多语言源头汇合**、训练级执行器、确定性并行、golden 哈希验收。核心目标:**语言的尽头就是模型**——10M 参数线性注意力基座 + BM25 检索流。

> 🇨🇳 中国 AI,从敢写第一行代码开始。

## 一句话哲学

**源头也是尽头。** 不发明新范式,而是吸收各语言最锋利的优点,拟合进量子驱动思维。**存算一体是骨架,语言优点是血肉。** 数据的读取即计算,读取即可能性。

## 语言源头矩阵(所有语言在此汇合)

星算语从**多源头语言**吸收基因,汇合到统一 XL01 字节码:

| 源头语言 | 前端 | 吸收的优点 |
|---|---|---|
| **C** | `c_core/` | 零抽象,位置原生映射地址,执行核 |
| **C#** | `cs_front/` | 托管元数据,统一中间表示 |
| **Rust** | `rust_gate/` `xl_compiler/` | 所有权/借用,变换链所有权,编译期查悬垂 |
| **Lisp** | `lisp_front/` | 纯函数/符号原语,同源递归 |
| **Haskell** | `haskell_front/` | 纯函数/惰性求值,变换即纯函数 |
| **Erlang** | `erlang_front/` | 消息即计算,流天然是消息通道 |
| **APL** | `apl_front/` | 符号化数组,符号原语已同源 |
| **Q#** | `qsharp_front/` | 量子门即语言,变换链编译成量子线路 |
| **J** | `jlang_front/` | 符号化隐式语言,极简词法 |
| **Python** | `stdlib_front/` 等 | 动态活力,胶水生态 |

**三符抽象层**: `▸` 位置(符号层) · `↦` 变换(神经层) · `⟶` 流(量子/流式层)。

## 工具链(全套自研,不依赖外部运行时)

| 工具 | 语言 | 作用 |

## 架构

```
多语言前端(C#/Lisp/APL/Haskell/Erlang/Q#/J/Python)
   → 统一 XL01 字节码(1字节opcode + 3字节operand, 三符版本头)
   → Rust 门禁(静态校验)
   → 字节码执行器 VM(C核, OpenMP确定性并行, 单/8线程逐位一致)
   → 训练出 loss + 五项哈希 golden(可重放可验收)
```

## 生态补全(P5/P6)

**P5 stdlib** —— 23 个通用算子(opcode 18-40+255): 字符串/集合/IO/mmap/控制流/常量,文件写→读回逐字节一致。

**P5 可视化/IO** —— 15 个算子(opcode 48-62): 画布/画笔/像素/填充/渲染,产出 **128×64 PPM 实证图**(`vis_front/out/vis_demo.ppm`)。

**P6 自举** —— `xl_compiler/src/type_system.rs` 量纲类型系统(自举第一阶段),在源语言里做静态分析。自举三阶段: ①量纲类型 ✓ → ②表达式+控制流 → ③数据结构+IO+用星算语重写 lexer。

**opcode 空间划界**: 1-17 训练锁定 / 18-47 stdlib / 48-62 可视化 / 64+ 预留。
