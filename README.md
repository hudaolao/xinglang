# XingLang · 星算语

> 存算一体的量子驱动编程语言 —— QCPU·驱动核编译引擎（C# 原生，完全脱离 Python）

星算语是一门自研的**存算一体**编程语言：数据在被读取和运输的过程中就已经完成运算。由 **QCPU·驱动核**（普适量子驱动算法）编译执行，源 → 字节码 → 驱动核，产物为独立 exe，与 Python 无关。

## 核心哲学

```
算力 = 量子寄存器
计算 = 量子态演化
结果 = 测量坍缩
读取 = 演化后测量 · 运输 = 流径上完成运算
```

**三符**：`▸` 位置 / `↦` 变换 / `⟶` 流 —— 星算语的三元语法，编译为量子驱动指令序列。

## 特性

- **完全脱离 Python**：C# 原生（.NET 8），产物为独立可执行文件，宿主无关
- **量子驱动内核**：N-qubit 态矢量、Hadamard / CNOT / 单比特门（H/X/Z/Pθ）、测量坍缩
- **存算一体符号原语**：`ℊ Ϝ K M G π e φ` 等（与 tri_drive 训练同源）
- **分派链 + 27 个指令方法**，词法 / 求值分离
- **量纲检查**：写回时防错单位落盘

## 构建与运行

```bash
# 需要 .NET 8 SDK
dotnet build
dotnet run
```
